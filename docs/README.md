# WanderWise AI: ドキュメントディレクトリ

このドキュメント用ディレクトリ（`docs/`）は、プロジェクトの設計書や各種仕様書を一元管理するために作成されました。
拡張性を高めるため、以下のルールの下で各フォルダに分類してドキュメントを配置してください。

## 📁 ディレクトリ構成

### `/api` (API・インターフェース関連)
- OpenAPI (Swagger) 定義書
- 外部API連携（OpenAI API等）の仕様書
- フロントエンド⇔バックエンド間のスキーマ定義

### `/db` (データベース関連)
- ER図、テーブル定義、スキーマ設計書
- Prisma / SQLAlchemy 等のモデル設計
- 初期データの仕様など

### `/infrastructure` (インフラ・環境構築関連)
- DockerやAWSなどのインフラ設計書
- CI/CDパイプラインの構成
- 環境変数(.env)の管理方針

### `/frontend` (フロントエンド関連)
- 画面遷移図、コンポーネント設計図
- デザインシステムやUI/UXに関する仕様
- 状態管理（State Management）のポリシー

### `/backend` (バックエンド関連)
- コアロジックの設計（RAGの処理フローなど）
- クラス図、シーケンス図
- ベクトルデータベース(ChromaDB)の設計方針

---
※ 各フォルダ内には、作成順または機能種別ごとにわかりやすいファイル名(例: `01_xxx.md` )を付けてドキュメントを格納してください。
